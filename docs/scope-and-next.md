# حدود النسخة وتسلسل العمل

نسخة v0.2 أعادت الصفحات إلى مكونات Tabler UI وأكملت وحدات المتبرع والمؤسسة والإدارة كمحاكاة محلية قابلة للتنقل. خريطة الواجهات المعتمدة ممثلة، والسيناريو الأساسي جرى اختباره من المتصفح. التفاصيل والحدود في README ونتائج الاختبار في QA_RESULTS.md.

الخطوة التالية مراجعة المستخدم لشكل الصفحات وتجربة الرحلات واعتمادها. بعد اعتماد النموذج فقط يُشتق Product Backlog وخطة التطوير الحقيقي. لم تُنشأ سبرنتات منتج في هذا التسليم.

تبقى المواعيد، وقواعد الأهلية والفصيلة، وسياسات الموقع والتدقيق الإنتاجي وكشف البيانات، ومدد OTP الفعلية، وقواعد العمل دون إنترنت بحاجة لاعتماد قبل تنفيذ Backend. القيم الحالية تجريبية فقط.

مراجعة الإكمال في 1 نوفمبر 2026 عالجت رابط تفاصيل طلب المدير، ووصلت مرشحي المؤسسة بسياق الطلب، وأكملت كشوف نقاط المؤسسة وتصفح التدقيق، وأضافت تعديل إعدادات المؤسسات مع السبب. توثّق خريطة الشاشات ورحلة المراجعة في [FRONTEND_HANDOFF.md](FRONTEND_HANDOFF.md). لا توجد وحدات Frontend مؤجلة ضمن النطاق المعتمد؛ التالي مراجعة المستخدم وتعديل ملاحظاته.
