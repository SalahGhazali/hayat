# حياة — Hayat

نسخة MVP تفاعلية لواجهات مشروع **Smart Blood Donation Management Platform**، مبنية باستخدام **HTML وCSS وJavaScript فقط**، دون مكتبات أو خطوة build أو خادم خلفي.

## التشغيل

افتح `index.html` مباشرة في المتصفح. تبدأ المنصة بحساب متبرع وبيانات عرض جاهزة. لا يحتاج التشغيل إلى تثبيت أي حزمة أو الاتصال بالإنترنت.

يمكن أيضًا فتح المجلد باستخدام Live Server في محرر VS Code. عند التشغيل على localhost أو HTTPS تُفعَّل خدمة التخزين المؤقت للعمل دون اتصال بعد أول زيارة. عند فتح الملف مباشرة تعمل الملفات المحلية دون Service Worker.

## التجربة

- **المتبرع:** لوحة تحكم، تصفية الطلبات حسب الفصيلة والمدينة، قبول الطلب أو الاعتذار، حجز المواعيد وتعديلها وإلغاؤها، سجل التبرعات وتنزيله CSV، حملات التبرع، دليل المراكز، الإشعارات والملف الشخصي.
- **مسؤول بنك الدم:** إنشاء الطلبات وتعديلها وإكمالها وإلغاؤها، مطابقة المتبرعين، تنبيهات محلية، تقارير، وتسجيل تبرع مكتمل من صفحة المواعيد في يوم الموعد أو بعده.
- **مدير النظام:** وظائف بنك الدم وإدارة المستخدمين والمؤسسات وإعدادات العرض.

للتبديل بين الأدوار: افتح **الملف الشخصي ← جرّب أدوار المنصة**. لتجربة التسجيل، سجّل الخروج ثم اختر إنشاء حساب تجريبي. استعادة البيانات الأولية متاحة من الملف الشخصي.

## حدود النسخة

جميع البيانات والمراكز والمواقع وساعات العمل والطلبات للعرض فقط. تُحفظ التغييرات في LocalStorage في المتصفح، ولا تُرسل إلى أي طرف. تسجيل الدخول وتغيير الأدوار محاكاة وليسا نظام صلاحيات آمنًا. لا توجد رسائل SMS أو إشعارات دفع خارجية أو حجوزات حقيقية. لا تستخدم معلومات شخصية حقيقية.

المطابقة تعتمد قواعد توافق خلايا الدم الحمراء لفصائل ABO وعامل Rh مع موقع تجريبي؛ وهي للمساعدة في فرز النتائج ولا تمثل تصريحًا طبيًا. فترة العدّاد الافتراضية **٩٠ يومًا اختيار تجريبي قابل للتعديل** وليست قاعدة طبية. يحدد بنك الدم أهلية التبرع والتوافق الفعليين بعد الفحص. لا تتضمن النسخة مخزون الدم أو الفحوصات السريرية أو المدفوعات، انسجامًا مع نطاق وثيقة المشروع.

## الملفات

- `index.html`: نقطة البداية.
- `styles.css` و`extras.css`: التصميم المتجاوب ودعم العربية وRTL.
- `data.js`: بيانات العرض الأولية.
- `app.js`: التصفح ومسارات المتبرع والطلبات والحجوزات والتخزين المحلي.
- `admin.js`: المطابقة والتقارير وإدارة المستخدمين والمؤسسات.
- `sw.js`: التخزين المؤقت الاختياري عند استخدام خادم ملفات محلي أو HTTPS.
- `assets/favicon.svg`: شعار حياة.

المجلد `.tools` مخصص لفحص التنفيذ محليًا ولا يدخل في تشغيل التطبيق أو تسليمه.
